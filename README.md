# 🎮 OOP Character System (C++)

A simple object-oriented character management system built in **C++** as part of my Object-Oriented Programming practice.

## 📖 Overview

This project demonstrates the core principles of Object-Oriented Programming by creating a character system similar to what you might find in a game. It focuses on clean class design, inheritance, and code organization rather than graphics or gameplay.

## ✨ Features

* Create and manage game characters
* Character attributes (Health, Attack, Defense, etc.)
* Character actions and methods
* Class inheritance
* Constructors and destructors
* Encapsulation
* Polymorphism 
* Clean header and source file structure

## 🛠️ Built With

* C++
* Visual Studio

## 📚 OOP Concepts Used

* Classes & Objects
* Encapsulation
* Constructors & Destructors
* Inheritance
* Polymorphism 
* Access Specifiers
* Header Files
* Separate Compilation

## 🚀 How to Run

1. Clone the repository.
2. Open the project in Visual Studio 
3. Build the project.
4. Run the executable.
5. Give a star if you liked it.

## 🎯 Purpose

This project was created to strengthen my understanding of Object-Oriented Programming in C++ and to practice writing organized, maintainable code that can serve as the foundation for larger game projects.
